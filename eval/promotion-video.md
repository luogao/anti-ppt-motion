# 本期唯一目标：真实对照，介绍开源 Skill

用同一模型、同一口播、同一内容和同等修改预算，比较未加载与加载 Skill 的真实输出。
新版 Skill 包括场景／镜头方法与可复用代码；这是产品的一部分，应明确说明。
定向编写的 9 秒参考片不用于本期效果对照，也不作为加载 Skill 的产物。

先检查本轮实际 A/B。内容、单位、可读性和音画不能退步；根据实际画面指出
可见增量，再确认这一对能否支撑介绍。若仍无明显增量，保留失败记录并继续
改 Skill，本期不编造成功结论。不能通过人工补镜头、替换 B 或削弱 A 制造差异。

## 约 60 秒，结果成立后才填定口播

| 时段 | 画面 | 要传递的事实 |
|---|---|---|
| 0–8s | 两组同时间段、等尺寸、等速度的实际画面 | 问加这份 Skill 会改变什么；不预填赢家 |
| 8–14s | 共同条件与 Skill 包内容 | 只有后一组多了 Skill 及其资源；数字是视频教学数据 |
| 14–24s | 未加载 Skill 的完整 10 秒原片 | 保留原声、标签和事实，不贬低已有能力 |
| 24–34s | 加载 Skill 的完整 10 秒原片 | 同规格、同声音处理，保留实际结果 |
| 34–44s | 同时间点回看 1–2 个具体变化 | 按实际输出说明对象、取景与承接怎样改变 |
| 44–55s | 实际开源版本与使用入口 | 说明 Skill 自带什么、适用的已测工作流与安装方式 |
| 55–60s | 真实结论与账号收尾 | 本例观察边界与完整对照入口，不泛化收益 |

呈现方案调整（2026-11-06，生成结束后）：原先选定的 4.6–8.1 秒不包含本例实际的
景别变化。改用两组共同的 0–3.5 秒，各展示 3.5 秒，中间 1 秒衔接，总计 8 秒。
这是看过输出后的展示窗口选择，不是预注册选择；两组保留同一时间段、尺寸和速度，
完整 10 秒原片同时提供。不得分别挑不同时间点，也不改生成的 Scene。
T2 画面中的 A/B、30秒/10秒是虚构教学方法和数据，不能让观众误会为
有无 Skill 的制作速度。实验组对外标为“未加载 Skill／加载 Skill”。

## 制作准入

先交付可直接播放的两份实验原片和清楚标明来源的对照页。确认实际增量后，
再用这对输出制作不超过 10 秒的真正片头样片，按现有 Gate 3 做结构确认。
随后才进入整期粗剪、文案冻结和成片验收；不自动发布抖音。
