# v0.2 diagnostic pilot — not a replacement for v0.1

Trigger: the owner watched the preselected v0.1 T1r1 comparison with group labels
and reported no convincing visible difference. This is production feedback from
an involved observer, not an independent blind vote. The v0.1 12-task batch and
all original outputs remain unchanged. The opening is not accepted for promotion;
the later rejection supersedes the earlier structure approval.

Hypotheses, not established causes: the first Skill mostly repeats broad
principles the baseline model already applies; 10-second one-scene tasks reveal
little about connected scenes. Test a more operational scene-composition method.

Candidate change: persistent subjects, explicit joins between beats, purposeful
framing and revision of repeated dashboard composition. It remains independent
of private Motion Kit and uses existing Remotion features.

One follow-up pilot: a new 30-second narrated queue/capacity explanation; both
arms receive the same new brief, audio, dimensions, starter and technical baseline.
Only B receives the candidate Skill and references. Use the same model/effort,
one generation plus one uniform review each, 600 seconds per call, no tools.
Review frames: 0, 5, 10, 15, 20, 25 and 29.5 seconds. Run order B then A. Save
all outputs, failures, hashes and actual usage. Do not manually improve B or
weaken A. If the pilot does not improve the result, keep that outcome too.

This topic and method were chosen after seeing v0.1, so this is a diagnostic
pilot, not preregistered confirmatory evidence or a direct 10s-vs-30s comparison.
No new full formal batch or promotional video until a useful, observable
difference is established. Human judgment is separate from render success.
