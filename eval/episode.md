# Episode: does this anti-PPT Skill help?

Plan: about 60 seconds, 1080×1440 at 30 fps. Actual result sentences stay unset
until the outputs and viewing evidence exist.

| Time | Picture / evidence | Narration purpose |
|---|---|---|
| 0–5s | Actual preselected T1r1 A/B; content visible from frame zero | Say what was tested and one supported observation |
| 5–12s | Same model, voice, assets and technical baseline; B adds this Skill | Explain the controlled difference |
| 12–25s | Equal-size/equal-speed excerpts of T1 | Identify one actual object/action/relationship difference |
| 25–38s | T2/T3 and complete-results summary | Show scope and ordinary/failed outputs |
| 38–49s | One observed change connected to the method | Explain intent, state change, spoken cue and revision |
| 49–57s | Actual public repository, frozen version and full case index | State availability and limitations, no unsupported claims |
| 57–60s | Result and account's fixed sign-off | Close using the actual result |

Opening branches: observed improvement, little/mixed difference, or regression.
Do not preselect a winning claim. Human comprehension and blind preference are
pending until real ratings exist. Full-screen alternating comparison should
preserve readability; brief paired thumbnails only establish identity.

Production gate: prepare a cold-open sample no longer than 10 seconds for
Luogao's structure review before a full-episode rough cut. Keep factual claims,
voiceover, final text and video QC within the existing account workflow.
