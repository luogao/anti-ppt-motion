# 观看与返修

先按正常速度完整播放，记录能理解什么，哪里不清楚。再回看关键时间段：

1. 主体与论点能否对应？证据是否真实、可见、可读？
2. 视线是否清楚？字幕、数字、主体是否同时争抢注意？
3. 关键动作是否对应口播？证据阅读和段落衔接是否合适？
4. 对象身份、数据口径与因果关系有没有在运动中改变？
5. 帧驱动、音画、规格和交接是否符合当前项目要求？

反馈写成“时间段 → 对象 → 问题 → 修改动作 → 复看结果”。例如：3.2–4.5 秒，数字尚在变，结论已经出现；先让数字落定，再强调结论，压缩无信息等待保持总时长。

只改有观察依据的内容。保留其他已确认信息和用户改动。静帧检查只支持构图、文字和位置结论；没有实际播放时，不宣称节奏、声画同步或观众理解已通过。
