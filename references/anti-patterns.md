# 从症状到修正

| 症状 | 先判断什么 | 可能的修改 |
|---|---|---|
| 标题换一页，正文再换一页 | 这些句子是否在解释同一个对象或过程 | 保留主体，让状态和关系推进；不同论题仍可切镜 |
| 卡片飞入但信息关系没变 | 动作是否帮助比较、解释或定位 | 让动作展示真正的差异或状态变化；无需运动的证据保持稳定 |
| 漂移、发光、粒子比证据更强 | 第一眼是否落在正在解释的东西上 | 降低装饰，让主体或证据承担主要动作 |
| 很多文字同时发生变化 | 观众是否有足够时间阅读，主次是否明确 | 分配观看顺序；让必要文字稳定，重点词适度强调 |
| 所有段落同一版式换字 | 相邻段的叙事任务是否不同 | 根据证据、过程或比较改变组织，而非只换颜色 |
| 运镜很忙但仍不清楚 | 每次镜头移动在跟随或揭示什么 | 明确目标；固定镜头与对象动作有时更合适 |
| 画面好看但结论无依据 | 是否缺录屏、数据或必要背景 | 补证据或收窄结论，不靠动画补造事实 |

“像 PPT”不是软件名称、运动量或截图能独立判定的属性。静态图表、文字与停顿也可有效表达。
